## Deskripsi Tugas

Membuat aplikasi GUI berbasis Tkinter untuk memprediksi Program Studi pilihan berdasarkan input 10 nilai mata pelajaran.

## Komponen Antarmuka (GUI)

1. **Label Judul**: "Aplikasi Prediksi Prodi Pilihan" pada bagian atas.
2. **10 Input Nilai**: Form input mata pelajaran 1 sampai 10.
3. **1 Button Prediksi**: Tombol bertuliskan "Hasil Prediksi".
4. **1 Label Luaran**: Menampilkan hasil prediksi prodi ("Teknologi Informasi").
