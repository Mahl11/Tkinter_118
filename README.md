# Tkinter_118 - Formatting GUI dengan TKinter

Tugas Praktikum Pemrograman Multiplatform: Implementasi GUI Formatting menggunakan library Tkinter di Python.

## Deskripsi Tugas
Membuat aplikasi GUI berbasis Tkinter untuk memprediksi Program Studi pilihan berdasarkan input 10 nilai mata pelajaran.

## Komponen Antarmuka (GUI)
1. **Label Judul**: "Aplikasi Prediksi Prodi Pilihan" pada bagian atas.
2. **10 Input Nilai**: Form input mata pelajaran 1 sampai 10.
3. **1 Button Prediksi**: Tombol bertuliskan "Hasil Prediksi".
4. **1 Label Luaran**: Menampilkan hasil prediksi prodi ("Teknologi Informasi").

## Fitur Aplikasi
- Desain antarmuka bersih dan rapi dengan latar belakang bernuansa biru gelap sesuai referensi praktikum.
- Penataan komponen menggunakan kombinasi `pack()` dan `grid()` untuk layout yang proporsional.
- Validasi input nilai mata pelajaran (memastikan tidak kosong, berupa angka, dan rentang 0-100).
- Hasil prediksi otomatis menampilkan prodi **Teknologi Informasi**.

## Cara Menjalankan Program
Pastikan Python sudah terinstal di komputer Anda:
```bash
python main.py
```
